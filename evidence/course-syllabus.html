Course Information:

Course Description

This course introduces the fundamental concepts of computer science and programming through Java. Students learn how computers represent information, how algorithms solve problems, and how programs use variables, data types, conditional statements, loops, methods, and basic object-oriented concepts. The course connects programming ideas to familiar examples, such as applications, games, and everyday decision-making. Class sessions combine short explanations, live coding, guided practice, discussion, and opportunities to ask questions. The emphasis is on understanding why a program works, not only on writing code that runs.

Prerequisites

No prior programming experience is expected for this proposed introductory course. Students should be comfortable with basic algebra, reading problem statements, and using a computer to manage files and access course materials.

Student Learning Outcomes

By the end of the course, students should be able to:

Explain foundational computer science concepts, including algorithms and basic information representation.

Write, trace, test, and debug Java programs using input/output, variables, expressions, and data types.

Design and implement solutions using conditional statements and loops.

Decompose problems into reusable methods with parameters and return values.

Describe and apply introductory classes and objects in a small Java program.

Explain a programming solution, justify design choices, and identify relevant ethical or social considerations in computing.

Required Materials / Technology

A computer with regular internet access and the ability to run Java programs.

A current Java Development Kit (JDK) and an editor or IDE such as IntelliJ IDEA Community Edition, VS Code with Java extensions, or an equivalent approved environment.

Access to the course learning management system for handouts, assignments, announcements, and feedback.

Instructor-provided notes, code examples, and free online readings; any required textbook will be identified before the course begins.

Outline of Topics

Foundations of computing and algorithms. Java environment and syntax. Variables, operators, input/output, and data types. Boolean logic and decision-making. Loops and debugging. Methods and program decomposition. Arrays and basic data structures. Classes, objects, and introductory object-oriented programming. A small applied programming project.

Exams & Assignments

Learning will be assessed using short programming exercises, practical assignments, low-stakes concept checks, an applied mini-project, and exams. Weekly exercises will ask students to explain their reasoning and test their code. Some class sessions will include ungraded quizzes to identify misunderstandings and allow students to ask questions before advancing to new topics.

Suggested letter-grade ranges: A = 90–100%; B = 80–89%; C = 70–79%; D = 60–69%; F = below 60%. Rubrics will assess correctness, clear reasoning, testing, readability, and progress toward learning outcomes. Ungraded checks used only for feedback will not affect the final grade.

Missed / Late Coursework Policy (Proposed)

Assignments are due at the time posted in the learning management system. Work submitted within 48 hours may receive up to a 10% deduction, after that students should contact the instructor to discuss a reasonable plan. Students facing illness, accessibility barriers, or other significant circumstances are encouraged to communicate as early as possible. Missed exams and any approved make-up arrangements will be handled consistently with applicable institutional policy. The goal is to maintain clear expectations while providing appropriate opportunities for learning.

Attendance / Participation Policy (Proposed)

Students are expected to attend regularly, participate in class discussion, and practice programming during and between meetings. Participation can include asking or answering questions, completing short coding activities, discussing approaches with peers, and explaining how a solution works. Students who miss class should review posted materials and contact the instructor when help is needed. Attendance procedures and excused absences will follow the applicable institutional policy.
