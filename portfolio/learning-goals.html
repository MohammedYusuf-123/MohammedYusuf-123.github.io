Planning Learning Goals and Outcomes

This course-planning activity develops a goal, objectives, and learning outcomes for a proposed Computer Algorithms course.

Purpose of the activity

Course planning requires an instructor to identify what students should learn and how they will demonstrate that learning. This activity separates a broad goal from objectives and outcomes. It also considers discussion and visualization as methods that could support learning in an algorithms course.

FROM THE COURSEWORK

Planning Learning Goals and Outcomes

The original goal is to solve real-life problems using algorithms. The objectives focus on designing and implementing algorithms. The outcomes include implementing and demonstrating 70% of the algorithms tested and solving a real-life problem using an appropriate algorithm.

The supplied document is preserved separately so the original work can be distinguished from the portfolio commentary.

02 / REFLECTION ON THE ACTIVITY

Reflection

The activity provides a starting point for describing what students should be able to do. However, the outcome referring to 70% of the algorithms needs more detail. It does not identify which algorithms are included or what level of implementation would meet the requirement. For example, a program may produce a correct answer for one input but fail for another. This means that the outcome should be connected to clear tasks and assessment criteria. A numerical target can communicate an expectation, but it does not describe every aspect of understanding.

03 / PROPOSED TEACHING APPLICATION

Future teaching application

A possible revision would ask students to select an algorithm for a specified problem, implement it, test it using defined cases, and explain why it is appropriate. I would then connect these requirements to the assessment criteria. This is a proposed refinement; the original course-planning activity is available separately.

AREA FOR FURTHER DEVELOPMENT

I would map each outcome to a learning activity and an assessment, and check whether the criteria make the expected performance clear to students.
